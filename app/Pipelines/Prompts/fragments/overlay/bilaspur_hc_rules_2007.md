# OVERLAY — CG High Court Rules 2007 (mandatory format quirks)

Source: highcourt.cg.gov.in/judicial/FilingInstructions.pdf

For any draft destined for CG HC Bilaspur:

## Mandatory checks (Section C)
1. Petition + applications + accompanying docs typed double-space, one side.
2. Particulars of impugned order uniform across all documents.
3. Addresses of parties + representatives complete + properly set out.
4. Cause title corresponds to cause title of impugned judgment.
5. Detailed cause title in impugned judgment OR memo of parties filed.
6. Petition + applications signed by counsel + petitioner.
7. Prescribed court fee paid.
8. Affidavit of petitioner in support of petition + applications filed.
9. Vakalatnama properly executed by petitioner + accepted by advocate +
   Memo of Appearance filed.
10. Annexures: true copies of docs before lower court + filed in
    chronological order.
11. If petition time-barred: condonation-of-delay application + affidavit
    + court fee filed (mention number of days delay).
12. If party died below: LR application with date of death + relationship
    + age + addresses + affidavit + court fee.
13. Paragraphs + pages numbered consecutively, indexed.
14. If identical matter pending/disposed → particulars given.

## Mandatory points (Section D)
- Certified copy of impugned judgment (or exemption application).
- Affidavit properly attested + identified.
- Memo of Appearance.
- Vakalatnama duly accepted.
- Proper court fee.
- Required number of paper-book sets (typically 5 for HC).
- Brief list of dates / events.

These items are registry-level rejections. Drafter must include all of
them; critic must flag any missing.
