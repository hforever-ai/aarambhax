# FORUM — Chhattisgarh Revenue Courts (CGLRC + CG Rent Control + Senior Citizens)

## Hierarchy
Tehsildar / Naib Tehsildar → SDO/SDM → Additional Collector → Collector
→ Commissioner → Board of Revenue, Bilaspur

## Format requirements (Hindi default, court-specific headers)

### Tehsildar / SDM / Collector
```
न्यायालय [श्रीमान तहसीलदार महोदय / अनुविभागीय अधिकारी / श्रीमान कलेक्टर महोदय],
[तहसील / जिला], छ.ग.
राजस्व प्रकरण क्रमांक: ............ / [अ-वर्ग] / [वर्ष]
```

## Revenue-specific vocabulary (use Devanagari, keep numerals as-is)

- खसरा क्रमांक (Khasra no.)
- खाता क्रमांक (Khata no.)
- खतौनी / बी-1 / पी-II (record-of-rights)
- रकबा (area, in हेक्टेयर)
- ग्राम / पटवारी हलका / राजस्व निरीक्षक मण्डल / तहसील / जिला
- नामांतरण (mutation)
- बँटवारा / बटवारा (partition)
- सीमांकन (boundary demarcation)
- व्यापवर्तन / भू-व्यापवर्तन (diversion of land use)
- अतिक्रमण (encroachment)
- वाद भूमि (the land in dispute)
- चौहद्दी (boundaries — उत्तर/दक्षिण/पूर्व/पश्चिम)
- पंजीकृत विक्रय विलेख (registered sale deed)
- दानपत्र (gift deed) / वसीयत (will) / सामलाती हक़ (community rights)
- अनुसूचित जाति / अनुसूचित जनजाति (SC/ST) — relevant for §170-B CGLRC

## Standard CGLRC sections invoked

- §59 — diversion (व्यापवर्तन)
- §107 — record correction (त्रुटि सुधार)
- §109 — mutation (नामांतरण)
- §115 — common land restoration (सामलाती हक़ / commons)
- §129 — boundary demarcation (सीमांकन)
- §165 — alienation permission
- §170-B — restoration of tribal land (CRITICAL — Schedule V areas + ST sellers)
- §178 — partition (बँटवारा)

## CG Rent Control Act overlay

If matter is rent control:
- Forum is also called भाड़ा नियंत्रक (Rent Controller), usually SDM-level.
- Common pleas: bona fide need (वास्तविक आवश्यकता), default in rent (किराया चूक),
  sub-letting (उप-किरायेदारी), structural changes, nuisance.
- Numbered facts establishing tenancy + grounds for eviction.

## Document references (mandatory)

Every revenue draft must reference the supporting documents — खसरा extract,
खतौनी, sale deed, mutation entry — in numbered annexures (दस्तावेज 1, 2, ...).
Failure to reference these is a registry-level rejection.
