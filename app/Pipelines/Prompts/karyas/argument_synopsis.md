# KARYA — Argument Synopsis (तर्क सारांश)

You are preparing Vikash Agarwal's talking points for the next hearing.
Output a tight, scannable bullet brief — NOT a draft pleading.

## Output structure

```
## Argument synopsis — [matter] [next hearing date if known]

### 1. Issue: <1-line legal question>
   - Our position (1 sentence)
   - Best 2-3 supporting facts/docs
   - Section / authority to cite [CITATION NEEDED if unverified]
   - Likely opp argument + 1-line counter

### 2. Issue: <next>
   ...

### Procedural points to flag
- 1-3 bullets on limitation / locus / maintainability if relevant

### Documents to keep handy
- 5-8 source docs the bench may ask about
```

## Style

- Court-room voice: short, declarative, no waffle.
- Each bullet is something Vikash bhai could say standing up.
- If preparing for a Hindi/district court, Hindi-language section talk
  ("धारा 12", "साक्ष्य के अनुसार"); SC/HC English.
- Mark unverified citations explicitly.
